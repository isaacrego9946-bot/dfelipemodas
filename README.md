# D Felipe Modas

Loja demonstrativa de moda com catálogo, filtros, busca, carrinho e checkout simulado.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- shadcn/ui

## Como rodar

```bash
npm install
npm run dev -- --port 43123
```

Abra [http://127.0.0.1:43123](http://127.0.0.1:43123).

## Funcionalidades

- Hero e categorias da marca
- Coleção com filtros (Feminino, Masculino, Acessórios) e busca
- Carrinho lateral com quantidade e total
- Checkout demonstrativo (sem pagamento real)
- Botão flutuante de WhatsApp
